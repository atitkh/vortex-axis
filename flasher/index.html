Flash a VorteX Axis board

Puts the VorteX Axis firmware on a new board over USB, from this page. You do this once: after that the board updates itself over Wi-Fi from your Axis.

This page was opened over plain http, where browsers do not allow USB access. Open it through your hub's https address, or from the machine Axis runs on as http://localhost:8440/flash.

Waveshare ESP32-S3-Touch-AMOLED-1.8
firmware

This browser cannot reach USB devices. Use Chrome or Edge on a computer (not a phone). This page has to be opened over https (or from localhost) to reach USB devices.

Before you press it

  1. Use Chrome or Edge on a computer. Firefox, Safari and phones cannot do this.
  2. Plug the board in with a USB-C cable that carries data. Many cables that come with chargers only carry power; if no port shows up, try another cable.
  3. Press Connect and install and choose the port named like USB JTAG/serial debug unit.
  4. If the board is not found, or the install stalls at the start: hold the board's BOOT button, plug it in (or tap RESET) while holding, let go, and try again.

You are asked whether to erase the board first. Say yes for a board that ran something else; say no to keep a VorteX Axis board's Wi-Fi and pairing. Installing takes about a minute.

After it restarts

  1. The board shows a network name like VorteX-Axis-XXXX. Join it from your phone; a setup page opens (or go to http://192.168.4.1).
  2. Pick your Wi-Fi and enter its password.
  3. On your Axis admin page, open Add a device, make a pairing code and copy the setup string into the same form.
  4. The board joins, pairs, and shows its face. Say "Hey Vortex", or tap the screen.

Prefer the command line? The same firmware is on the project's releases page, with instructions in docs/hardware.md.
