OpenClaw

Axis joins your gateway as one device with two links: one sends turns to an agent, the other lets agents speak through Axis.

  1. On the gateway host run openclaw qr --setup-code-only, paste the result above and press Pair.
  2. Approve the device on the gateway: openclaw devices list, then openclaw devices approve <id>. Two requests come in, one after the other: first the device, then its request to also act as a node. Axis retries every 10 seconds.
  3. Allow Axis's commands in the gateway config under gateway.nodes.commands.allow:

Agent

Who answers when someone speaks to a client.

Speech

OpenAI-style endpoints. Recognition is /v1/audio/transcriptions; synthesis is /v1/audio/speech, asked for raw PCM.

Clients

Devices paired with this hub. Room and volume are stored here and sent to the device.

To try it from a browser, open the web client and enter a code.

A hardware device takes the address and the code as one setup string, pasted into its own setup page. Use an address the device can reach from its Wi-Fi: usually this machine's LAN address and port, not a Tailscale name.

Shared settings

Apply to every client unless a client has its own value. Nothing here is required: an empty setting means Axis uses the fallback shown next to it.

Other settings

Any other key is passed to clients as it is, for firmware that wants its own options.
