    Add a device

    A code works once and expires after 10 minutes.

    An address the device can reach over its Wi-Fi, usually this machine's LAN address and port. Not a Tailscale name.

    Paste into the device's own setup page (its VorteX-Axis-XXXX network, then http://192.168.4.1).

    Open the web client and type the code.

    OpenClaw

    Pairing steps
    1. On the gateway host run openclaw qr --setup-code-only, paste it above and press Pair.
    2. Approve the device: openclaw devices list, then openclaw devices approve <id>. Two requests arrive one after the other: the device, then its node role. Axis retries every 10 seconds.
    3. Allow these under gateway.nodes.commands.allow:
